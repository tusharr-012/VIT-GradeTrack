# Project Statement

## Project Title

VIT GradeTrack

## Problem Statement

Students have to keep track of different subjects, marks and attendance. Managing this information manually can become confusing.

This project provides a simple command-line Python program where a student can add subjects, view subject details, enter marks, check attendance and analyze marks.

## Objective

The objective of this project is to develop a simple student academic tracker using basic Python programming concepts such as variables, conditional statements, loops, lists, dictionaries, functions and modules.

## Main Functions

1. Add Subject
2. View Subjects
3. Enter Marks
4. Attendance Check
5. Marks Analysis
6. Search Subject
7. Delete Subject

## Input

The program takes subject names, subject codes, marks and attendance percentage from the user.

## Output

The program displays subject information, entered marks, total marks, attendance status and basic marks analysis.

## Programming Language

Python
